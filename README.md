# RidingTheHeatwave
Marimo code for blog on www.science4performance.com<br>
This repository supports the app in HeatOfTheMoment.py which forms the basis of Riding the Heatwave: Part 1.<br>
In Part 1: Balance of Power explores the physics of thermoregulation when cycling in hot weather. Internal energy is generated in the muscles as they deliver mechanical work. This heat must be dissipated through convection, radiation and evaporation of sweat. Any excess heat raises core body temperature.
